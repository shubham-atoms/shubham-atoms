# Shubham Aggarwal
Problem Setter at Atom Technologies / HackerRank. Based in New Delhi, India.

## About
I'm a Problem Setter building full-stack coding assessments for HackerRank's enterprise clients. My work involves designing realistic, production-grade applications that serve as coding challenges — from defining problem statements and planting deliberate bugs to writing comprehensive test suites and reviewing submissions. I focus on creating assessments that are fair, technically rigorous, and reflective of real-world engineering work.

## Current work
Building and curating CodeRepo-style assessments — full-stack applications where candidates diagnose and fix bugs across the stack. Each assessment is a working app with a `solution-prod` branch (all tests green) and a `base-prod` branch (tests failing due to planted issues). I also design "Build Your Own" assessments where candidates architect and build complete applications from scratch, evaluated on product depth and engineering judgment.
